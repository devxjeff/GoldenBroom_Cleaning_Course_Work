## Backend 
1. Create a database called goldenbroom (pgAdmin or: createdb -U postgres goldenbroom)
2. psql -U postgres -d goldenbroom -f schema.sql
3. Copy .env.example to .env and fill it in (set a real JWT_SECRET, ADMIN_USER, ADMIN_PASS)
4. npm install
5. npm run seed-admin
6. npm start  ->  http://localhost:3000   (customers: /portal.html, admin: /admin.html)
